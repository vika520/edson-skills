# 电商图片编辑（图生图）

适用于：改风格、改图中文字、重新排版、生成白底电商主图、按参考图复刻重绘。

## 流程

1. **拿参考图 file_id**：本地 `client.upload(path)`；或 URL 直接传 `image_urls`。
   - 多参考图（如「商品图 + 风格参考图」）一次传多张，模型会综合参考。
2. **编辑生成**：
   ```python
   task = client.edit(
       prompt="<见下方固定提示词>",
       file_ids=["file_product", "file_style"],
       model="gpt-image-2",
   )
   ```
3. **下载**：`client.download(task, out_dir="out")`。

## 固定提示词（核心，逐字使用）

**电商主图复刻/重构**（最常用）：
> 请根据提供的参考图，生成1张1:1比例的电商主图，所有文案均使用英文。具体要求：根据参考图文案重新设计排版主图

**改图中文字**：明确说明「保持构图与主体不变，仅把图内文字改为 <目标文案>，字体风格与原图一致」。

**改风格**：说明「保持商品主体、构图与文字信息不变，将背景/风格改为 <目标风格>」。

## 多图批量

- 输入图 ≤16/任务、输出 ≤4/任务；更大批量分批。
- 同一商品出多个角度/版本：循环调用 `edit`，每次换提示词（如「俯拍图」「场景图」），保持商品参考图不变以维持一致性。

## 铁律

1. 固定提示词逐字使用，不得替换成自拟风格描述。
2. 商品主体保真优先：要求「主体形状、颜色、文字与参考图完全一致」。
3. 402 = 余额不足 → 提示充值；失败任务读 `error` 原文报告。
4. 结果 URL 约 1 小时有效，拿到即下载。
