# 商品套图（listing 图集编排）

API 只提供原子能力，套图 = 脚本层按「套图计划」循环调用 `edit`。本技能给出标准计划与提示词骨架。

## 输入

- 商品主图 1~3 张（不同角度更佳），先 `upload` 拿 file_id。
- 用户指定的目标平台（Amazon/Shein/TikTok/独立站）与目标语言（默认英文）。

## 标准套图计划（6 张，可按需裁剪）

| # | 类型 | 比例 | 提示词骨架（拼在「根据提供的参考图」之后） |
|---|---|---|---|
| 1 | 白底主图 | 1:1 | 生成1张1:1比例的电商主图，纯白背景，所有文案均使用<语言>。要求：商品居中占画面 70-85%，无阴影无道具 |
| 2 | 卖点图 | 1:1 | 生成1张1:1的卖点图：左侧商品，右侧列出 3 个核心卖点（短句+图标式排版），文案使用<语言>，卖点从参考图商品特征提炼 |
| 3 | 场景图 | 1:1 | 生成1张1:1的使用场景图：商品置于真实使用场景，画面自然，不加文字 |
| 4 | 细节图 | 1:1 | 生成1张1:1的细节特写：突出材质/工艺细节，浅色干净背景，可加 1 处短标注（<语言>） |
| 5 | 尺寸信息图 | 1:1 | 生成1张1:1的尺寸信息图：商品正视图 + 尺寸标注线与数值（<语言>，单位换算合理） |
| 6 | 多角度/包装图 | 1:1 | 生成1张1:1的补充图：与商品相关的第二角度或包装展示 |

## 编排脚本模式

```python
plan = [...]  # 上表的 (类型, prompt)
file_ids = [client.upload(p) for p in product_images]
for kind, prompt in plan:
    task = client.edit(prompt=prompt, file_ids=file_ids, model="gpt-image-2")
    client.download(task, out_dir=f"out/{product_name}", prefix=kind)
```

- 顺序执行（服务端每账户并发受限）；单任务失败记录后继续，最后统一报告。
- 每张约 36 积分（以 `/agent/v1/models` 返回单价为准）；开跑前可 `account()` 查余额并告知用户预计消耗。

## 平台规范提示（拼进提示词）

- **Amazon**：主图必须纯白背景、无文字无道具无场景（第 1 张铁律）。
- **Shein/Temu**：允许浅色场景底 + 少量文字。
- **TikTok Shop**：允许生活化场景与促销角标。

## 铁律

1. 同一套图共享同一组商品参考图 file_ids，保证商品一致性。
2. 每张的提示词骨架逐字使用，平台/语言按用户要求替换占位符。
3. 402 → 停止并提示充值；不要为省积分跳过主图白底约束（平台会拒审）。
